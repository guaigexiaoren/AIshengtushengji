# 亦欣 AI 生图工作台

Windows 10/11 x64 桌面生图工具，使用 Nano Banana 三个型号生成和编辑图片。

## 当前功能

- Nano Banana 2.1、Nano Banana 2、Nano Banana Pro 切换
- 自动推荐模型，可选“质量优先”或“性价比优先”两套本地规则；判断不产生额外请求或费用
- 文字生图与 1–14 张参考图编辑，支持图片、文件夹和拖拽导入，并分别记忆上次目录
- 批量换装支持一对一、自由组合和自动匹配；可拖入文件/文件夹、裁剪恢复、拖动排序，并按窗口宽度自适应列数
- 首次升级内置基础服装替换和多图换装提示词，可在模板管理中编辑或删除
- 参考图和结果图统一编号预览，点击缩略图查看大图
- 参考图支持拖拽调整顺序、自由裁剪和恢复原图
- 参考图可拖拽调整顺序，并支持自由裁剪和恢复原图
- 单击创作页任务可恢复模型、提示词、参考图和全部生成参数
- 默认参考图编辑、`3:4`、`2K`，单次最多生成 4 张
- 串行后台队列、重启恢复、修改参数后重试和停止等待
- 队列和历史任务显示从提交到完成的总耗时
- 队列和历史显示从提交到完成的总耗时，执行中实时更新
- 历史记录、作品库、标签、搜索、提示词模板
- 作品库支持手动上传图片、递归导入文件夹和直接拖入文件或文件夹
- 作品详情显示实际保存路径，可一键打开所在文件夹
- 结果可分别保存到本地或作品库
- 创作页参考图与结果拖动分界线对比
- 管理员统一配置账号级 API Key，数据库密文保存、日志脱敏
- PyInstaller onedir 打包，数据固定保存在 EXE 同级 `data`
- 自定义深蓝星芒画笔图标，覆盖 EXE、窗口和任务栏
- 运营、AI 制作、管理员三角色登录，同一安装包按权限显示工作区
- 内网 MySQL 协同任务、子任务、并发领取、退回返工和完整状态审计
- 自动配对与手动配对；每张模特图为一个子任务并关联全部衣服图
- 生成图和手动 PS 成品写回共享盘，AI 自审选图后由运营验收通过或退回
- 管理员维护账号、模型单图成本、共享目录和共享提示词模板
- 按任务、货号、人员、模型和日期统计成本、耗时、返工与产出，并导出 Excel

## 协同业务闭环

1. 运营进入“AI图提交 → 新建任务”，系统定位账号当天日期并扫描货号目录。
2. 每个货号生成一个总任务，每张模特图对应一个子任务，子任务自动关联全部衣服图。
3. 任务编码自动生成：`账号显示名称-货号-当日流水号`。
4. AI 在任务中心领取任务、写提示词、并发生成或上传 PS 成品。
5. AI 勾选任意数量可用成品后提交待审核。
6. 运营查看参考图与成品对比，通过或填写修改点退回。

固定目录结构：

```text
\\10.6.6.6\AI作图\<账号显示名称/项目名>\<日期>\<货号>\衣服图
\\10.6.6.6\AI作图\<账号显示名称/项目名>\<日期>\<货号>\模特图
<货号目录>\AI成品\_r001_01_<哈希>.png
```

最终图片长期保留；未选中的候选图保留 30 天后自动清理。

## 安装与首次配置

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

数据库连接、共享盘地址和 API Key 加密主密钥已内置，普通用户不需要填写数据库设置。

首次启动时：

1. 数据库没有账号时，程序会要求创建首个管理员。
2. 管理员创建运营和 AI 制作账号，并设置每日加急额度和生成并发数。
3. 管理员在“用户与权限”中为每个 AI 账号配置 API Key。
4. AI 人员登录后直接使用管理员配置的 Key，不再看到 API Key 输入入口。

也可以使用命令行初始化数据库：

```powershell
.\.venv\Scripts\python.exe tools\init_mysql.py --host 数据库地址 --database ai作图 --user 数据库账号
```

数据库连接参数写在私有配置模块中并打进 EXE。正式部署时应使用仅拥有业务表增删改查权限的专用账号，并限制数据库来源 IP。
数据库管理员可参考 `tools/create_runtime_mysql_user.sql` 创建该账号；不要把建表账号配置到普通员工电脑。

设置页还可以选择本地保存方式：

- 每次询问：每次保存选择文件夹，并记住上次目录
- 固定文件夹：直接保存到指定目录
- AI图文件夹：使用任务最后一张参考图所在目录的上一级，并创建或复用 `AI图`

“保存到本地”只复制当前结果图；“保存到作品库”会同时保存结果、参考图、提示词和参数。
本地保存成功后使用右下角短提示，约 3 秒自动消失，不会阻塞后续操作。
本地保存文件名为 `AI图_日期_时间_结果序号.原扩展名`。

## 自动化测试

```powershell
$env:QT_QPA_PLATFORM='offscreen'
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

测试使用模拟接口，不会发起真实付费生成。
如需跑真实 MySQL 事务测试，设置 `YIXIN_TEST_MYSQL_HOST`、`PORT`、`DATABASE`、`USER`、`PASSWORD`；测试库名必须以 `_test` 结尾，普通运行会跳过该测试。

## 打包

```powershell
.\.venv\Scripts\python.exe -m pip install pyinstaller
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean 亦欣AI生图工作台.spec
```

输出目录：

```text
dist\亦欣AI生图工作台\亦欣AI生图工作台.exe
```

首次启动后会创建本机数据：

```text
data\config  加密配置
data\temp    临时结果
data\library 正式作品
data\logs    脱敏日志
data\app.db  历史、模板、标签和设置
```

每张作品保存在 `data\library\<作品文件夹>\`，其中包含：

```text
output.png 或原格式生成图
reference_01.png 等参考图
thumbnail.jpg 缩略图
```

首次升级旧版本时，程序会把旧 `data` 自动压缩备份到其同级目录，并停用旧 SQLite 数据库；旧历史不再显示。升级时只替换 EXE 和 `_internal`，不要覆盖新版本生成的 `data`。

图标源文件位于 `assets/app_icon.svg`。修改后运行
`python tools/build_app_icon.py` 可重新生成 PNG、ICO 和尺寸预览。

## 真实接口验收

真实调用会产生费用。只有管理员已配置有效 API Key，并经用户明确同意后，才使用 `n=1` 做一次文字生图和一次参考图编辑验收。
